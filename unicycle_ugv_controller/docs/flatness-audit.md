# Flatness state and q-p audit (#93)

This changes command-state lifecycle and adds observations; `common_types.cpp` (the current continuous low-speed law) is byte-identical to 479e1f01. No NMPC, estimator, IMU, Reset, chassis limit or planner feasible-set changes are made.

`body_speed_` is the bounded command integrator, not measured speed. Normal updates remain `v_c[k+1]=clip(v_c[k]+a_parallel[k]*dt)`. When the existing error/exit path issues zero, it now also sets `body_speed_=0`. Previously a later valid tick could reuse a pre-stop nonzero command. This is synchronization with a real stop command, not conditional gain scheduling. Measured signed longitudinal speed continues to be `cos(yaw)*vx_world+sin(yaw)*vy_world`, used in the existing damped inverse, never replaced by the command state.

The diagnostic topic is `<cmd_vel_topic>/flatness_audit` (`std_msgs/String`, JSON v1, queue 1). It emits only along the existing Flatness command-publication cadence. Its sample contains the exact lifted q, measured p/world velocity, signed speed, command integrator before/after, gains and source/receipt/control times used in that computation. The wrapper records publisher ROS time and the final box-clamped command. `sample_matches_command=false` explicitly identifies a queued output event whose sample no longer corresponds to the command consumed; do not use such rows for command-response matching. The diagnostic does not create a new command timer or source of feedback. Missing rows remain missing, not interpolated away by the publisher.

All time fields are seconds. `state_source_time_s` is the supplied state's stamp (which can itself be a reception fallback upstream); `pva_receipt_time_s` is the controller's cached receipt stamp, NOT the future PVA header stamp. `control_time_s` is the computation epoch, not hardware execution. Positions/velocities retain the controller's existing shared-world-frame contract. Verify that frame contract using the expanded YAML/TF receipt; this message must not manufacture a transform.

At each valid row, compute q-p in world coordinates, tangent/normal projections with measured yaw, q curvature only where q speed is nonzero, and raw yaw demand from the recorded unchanged formula. Report missing/mismatched rows and interval coverage before RMS/P95/max. Keep planner r-q analysis separate; this topic cannot reconstruct the mission reference r or prove collision-free planning.

Run `python3 unicycle_ugv_controller/test/test_flatness_audit.py`. It compiles the production serialization header with warnings as errors, exercises nonfinite observations and output-event stamp mismatches, and guards the actual stop wiring and unchanged law blob. This is NOT a full FSM/ROS/Gazebo test. Before adoption, exercise an invalid-reference/long-dt stop followed by resumed valid PVA, verify the first resumed integrator starts from zero (not stale pre-stop speed), record diagnostic coverage, and execute the frozen fixed-PVA, full four-vehicle and formal Experiment gates. Publication overhead and all motion acceptance remain unmeasured until those runs.
